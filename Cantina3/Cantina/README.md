# 🍔 Cantina Chichilo - Sistema Web Front-End Interactivo

Este fue mi primer proyecto en el desarrollo web, diseñado para simular la plataforma digital de un establecimiento gastronómico ("Cantina Chichilo"). El objetivo principal fue construir una interfaz atractiva, accesible y fluida para el usuario, aplicando las bases del desarrollo Front-End nativo.

## 🚀 Arquitectura y Tecnologías
El proyecto está construido utilizando estándares web modernos de forma nativa, asegurando una carga rápida y una estructura limpia:
* **Maquetación Semántica:** HTML5 (`index.html`) para garantizar un documento estructurado y accesible.
* **Estilos y Diseño Visual:** CSS3 para la distribución de componentes, manejo de tipografías y el diseño estético de la interfaz.
* **Interactividad Dinámica:** JavaScript (`js`) para controlar la lógica del lado del cliente y mejorar la experiencia de usuario dentro de la plataforma.

## 🗂️ Estructura del Proyecto
* **`/CSS`:** Hojas de estilo centralizadas para el diseño visual del sitio.
* **`/imagen`:** Repositorio de recursos multimedia e iconografía del sistema.
* **`/js`:** Scripts de JavaScript encargados del comportamiento interactivo del aplicativo.
